# Foodie Express

A food ordering web app built with PHP and MySQL as a learning project.

## Features

- Browse food categories and menu items
- Search for food
- Place orders
- Admin panel to manage admins, categories, food and orders

## Tech stack

PHP · MySQL · HTML · CSS

## Run locally

1. Install a local PHP and MySQL server, such as XAMPP.
2. Copy the `food-order-website-php` folder into the web root (`htdocs` in XAMPP).
3. Create a database named `food-order` and import `food-order-website-php/food-order/food-order.sql`.
4. Check the database settings in `config/constants.php`.
5. Open `http://localhost/food-order-website-php/`. The admin panel is under `/admin/`.

For local learning use only: it is not hardened for production.
